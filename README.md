# Progam Kasir Python Sederhana
Progam ini adalah sistem aplikasi kasir berbasis konsol sederhana yang di bangun menggunakan bahasa pemrograman Python. Dirancang untuk mengelola transaksi pesanan di sebuah restoran dengan fungsionalitas dasar.

## Fitur
- Input Nama Pelanggan dan Nomor Antrian
- Pencatatan Pesanan
- Menghitung Subtotal
- Menghitung Pajak
- Menghitung Kembalian

### Cara Menggunakan
# Windows
-Install Python di https://www.python.org/downloads/
-Pastikan Python Sudah terinstal dengan python --version
-Buka Command Prompt
-Clone Repository
-cd kasir
-Jalankan python kasir.py
# Linux
- Pastikan Python Sudah terinstall dengan python --version
- Buka Terminal
- Clone Repository
- cd/mv kasir
- Jalankan python kasir.py
# Termux
- pkg install
- pkg update && pkg upgrade
- pkg install python
- Pastikan Python sudah terinstall dengan python --version
- clone repository
- cd kasir
- jalankan python kasir.py

NOTE: Sistemnya baru bisa menerima satu menu, next update bisa banyak menu.
